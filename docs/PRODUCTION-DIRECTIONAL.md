# Real pul versiyası üçün qalan işlər

Bu branch yalnız virtual demo qurur. Aşağıdakı hissələr hazır real xidmət kimi təqdim edilmir və real pul aktivləşdirilməyib.

1. **Qiymət provayderi və qaydalar.** Kripto, FX/metallar və səhmlər üçün istifadə/lisenziya hüquqları olan axın seçilməli, tick timestamp/sequence, gecikmə, bazar sessiyaları, tətil, simvol mapping, korporativ hadisələr və dağıtım icazələri yoxlanmalıdır. 3/5 saniyəlik məhsul üçün provayderin ölçülmüş tezliyi və SLA-sı uyğun gəlməlidir. Yeni mənbə ayrıca adapter, sabit müqavilə qaydaları və auditli replay testləri olmadan aktiv edilməməlidir. simulation-v1 real pul üçün istifadə oluna bilməz.

2. **Maliyyə təminatı.** Bu məhsul spot kripto alış-satışı deyil: nəticəyə bağlı sabit qaytarılma öhdəliyi yaradır. Qarşı tərəf modeli, qalib ödənişlərinin kapital təminatı, maksimum açıq risk, rezervlər, müstəqil uzlaşma, müştəri və şirkət aktivlərinin ayrılması və itkilər üzrə məsuliyyət müəyyən edilməlidir. Demo sistem hesabının mənfi qalığı həqiqi kapital deyil. Real hesab üçün öhdəliklər təminat və risk mühərriki olmadan qəbul edilməməlidir.

3. **Kripto və dollar uçotu.** Custody/ödəniş provayderi müqaviləsi, təsdiqli ünvanlar, webhook imzası, şəbəkə finality/reorg, təkrar hadisə deduplikasiyası və çıxarış təsdiqləri lazımdır. real_conversion_receipts yalnız gələcək uçot skeletidir: provider_event, crypto_asset, crypto_amount, usd_rate, fee_usd, credited_usd, denomination və vaxt saxlayır. Hazır kreditləşdirmə yolu yoxdur. Gələcək provayder adapteri bu qəbzi balans jurnalına atomik bağlamalı, məzənnə mənbəyi/zamanı, rounding, USDT/USD bazis fərqi və konvertasiya riski saxlanmalıdır. Daxili USD vahidi bank depoziti deyil; USDT ayrıca token və ayrıca denominasiyadır. Hazır demo depozit/çıxarış qəbul etmir və saxta ünvan yaratmır.

4. **İstismar.** Dəqiq saat sinxronlaşdırılması, fasiləsiz feed/settlement işçiləri, multi-instance liderlik/lease, alerting, tutum və gecikmə ölçülməsi, Neon connection pooling, tick partition/arxiv, WORM xarici audit, disaster recovery, backup bərpa sınağı, təhlükəsizlik auditi və penetration test lazımdır. DB tətbiq/worker/migration rolları ayrılmalıdır. İndiki immutable triggerləri DB sahibinə qarşı hüquqi dəyişməzlik zəmanəti deyil.

5. **Hüquqi fəaliyyət ölkəsi.** Ölkə və xidmət göstəriləcək müştəri ölkələri müəyyən edilməyib. Bu məhsulun binary option/törəmə/mərc kimi təsnifatı yerli səlahiyyətli hüquqşünas və tənzimləyici ilə qiymətləndirilməli; tələb olunan icazə/lisenziya, mümkün qadağalar, yaş/rezidentlik yoxlaması, KYC/AML, sanksiya yoxlaması, vergi, məlumatların qorunması, reklam və şikayət qaydaları tamamlanmalıdır. Kripto ödəniş qəbul etmək məhsula hüquqi icazə vermir. Bəzi ölkələrdə pərakəndə müştərilərə belə məhsullar qadağandır. Məsələn [FCA](https://www.fca.org.uk/consumers/binary-options-scams) UK-də pərakəndə binary option satışının 2 aprel 2019-dan qadağan olduğunu bildirir. Avropa üzrə [ESMA product intervention](https://www.esma.europa.eu/investor-corner/product-intervention) və hər hədəf ölkənin milli qaydaları ayrıca yoxlanmalıdır.

6. **Aktivləşdirmə.** Hüquqi icazələr, kapital/custody/qiymət müqavilələri və əməliyyat təhlükəsizliyi yoxlanandan sonra ayrıca açıq göstəriş, ayrıca real ledger və buraxılış auditi tələb olunur. Bu demoda env dəyişəni ilə real pula keçid yoxdur.
